# Mailbox functionality — 0.8.3

Implemented on 2026-09-18 from the reviewed backlog. Offline mail is deliberately excluded: only the public application shell is cached.

The Inbox uses one select/clear checkbox and a floating Compose button. Advanced search opens from the sliders icon beside Search. Settings contains the account filter, folder/label management and notifications. Sidebar navigation shows standard views and shared labels; provider folders remain available in Settings and move destinations. Compose uses a docked desktop window and a full-screen mobile editor, with inline recipients, optional Cc/Bcc and attachment chips.

| Area | Available functionality | Provider requirements and bounds |
| --- | --- | --- |
| Sending and drafts | Compose, reply, reply-all, forward, attachments, original-mailbox draft creation/editing, review before sending, SMTP settings and connection test | Connected sender only; 100 recipients, 200,000 text characters, 25 MiB outgoing attachments. Microsoft accounts connected before this release need renewed SMTP consent. TLS is required. |
| Message actions | Read/unread, star, archive, move, Trash, restore, spam/not spam, Undo | Moves require a verified destination and native IMAP MOVE; Undo requires the provider's returned UID mapping and expires after 15 minutes. Gmail archive removes Inbox membership. |
| Bulk actions | Select messages or the first 50 loaded messages; flags, labels, moves and deletion with per-message results | At most 50 messages per operation; move destinations belong to the selected account. Failures are reported without silently retrying. |
| Search | Full-body query, all-folder view, sender/recipient/subject/body, date, read/star state, attachment and size filters | Provider searches and bounded, identity-checked pagination. Generic cross-folder views may include distinct stored copies; Gmail All Mail avoids label aliases. |
| Reading | Complete text, sanitized HTML, safe CID images, CC/Reply-To, raw headers and EML export | 160 MiB raw source, 8 MiB combined rendered text/HTML. Remote images and active content are blocked. |
| Encrypted mail | OpenPGP, PGP/MIME, RSA S/MIME EnvelopedData with user-supplied keys | Keys/passphrases are request-only and never stored or sent to AI. Signatures are explicitly unverified. Other encryption algorithms may be unsupported. |
| Folders and labels | Browse/create/rename provider folders; manage custom categories; synchronize existing and new categories as Gmail labels or one primary category folder for other providers; manually edit provider labels/keywords | Native MOVE + UIDPLUS required for filing. Sent, Drafts, Spam, Trash, Archive, completed retention and Keep decisions preserve placement. Gmail supports all categories; other mailboxes receive one primary folder, with manual choices preferred. Sync status/retry is in Manage folders & labels. |
| Updates and notifications | Automatic Inbox STATUS checks and opt-in Web Push notifications | Server checks once per minute while a view is active or a device subscribed. Browser checks for changes every 30 seconds. Notifications are generic and need browser/OS support and permission; no mail is cached offline. |
| Conversations and sorting | Group loaded messages using References/In-Reply-To; newest/oldest, subject and sender ordering | Conversation groups cover loaded pages and remain separated by account. Load more includes older replies. |
| Trash | Permanent deletion of selected Trash messages; empty Trash in batches of 100; restore to Inbox | Explicit confirmation and UIDPLUS required. Only selected, verified UIDs are expunged; no blanket EXPUNGE fallback. New arrivals during an empty operation are preserved. |
| Attachments | Individual downloads, supported image/text/PDF viewing, download-all ZIP, DOCX/XLSX/PPTX text previews | 100 MiB decoded per attachment and combined ZIP. Office previews: 25 MiB input, 32 MiB expanded XML, 1,000 ZIP entries; previews omit complex formatting. |

All original backlog areas except offline mail have implementations. The bounds above remain intentional. This is not a claim of universal provider support or a live end-to-end delivery test: SMTP delivery, device push delivery and encrypted formats depend on external accounts, browsers and message formats.

Category synchronization uses encrypted durable work records and MOVE intents. Interrupted moves recover only an exact unique destination identity; uncertain identities require review after bounded retries. It cooperatively drains the organizer before filing and preserves classification/retention deadlines. Gmail keeps unrelated labels and flags. This is forward synchronization: provider-side changes are not imported into category decisions. Clearing categories does not restore a guessed previous folder, and obsolete empty provider folders are not deleted. Existing categories backfill in bounded background batches.
